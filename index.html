Stock & sales merger

Drop your monthly sales files, the product list and the supplier arrivage. The page finds which file is which, matches everything on the EAN, and builds one table. Nothing leaves your browser.

How to use this website (detailed)
1) Prepare your files
  • Produit (product master) – needs EAN/barcode and internal product code. This is the bridge to link codes ↔ EANs.
  • Monthly files (Mois_08, Mois_09, Mois_10 or any future month) – sales/stock per month. Put the month number in the filename.
  • Arrivage Disty – supplier file. Ideally has product code, Prix Achat (HT) and Prix Vente (TTC). If it also has Qté/Quantité/Reçu, it will be pulled in as Qté Arrivage.
  • Ma Config – current stock (optional but supported).
2) Upload
  • Drag & drop all files together, or click to choose. You can upload many at once.
  • The page auto-detects which file is which and which header is which.
3) Check mapping
  • Look at the file list: each shows its role and detected headers.
  • If auto-detect is wrong, use Force role on that file (Mois / Produit / Arrivage / Ma Config / Ignorer) and it rebuilds instantly.
  • Edit Header names the page understands if a header uses a new name. Your changes are saved in this browser.
4) Matching rules
  • EAN is primary. Matched by EAN when present.
  • Code fallback. If EAN missing, matched by exact internal product code across files, then EAN is retrieved from Produit and propagated.
  • Bridge via Produit. Monthly files with only codes connect through Produit (EAN ↔ code).
  • No invention. The system will never invent EANs. Rows with neither EAN nor code stay unmatched (shown in yellow).
5) Results & export
  • Moyenne mensuelle = average of available monthly quantities only. Missing months are excluded. Months with 0 sales are included.
  • Use search to filter. Click column headers to sort.
  • Export XLSX or CSV with the buttons at the top.
Tips
  • Keep leading zeros in EANs — they are normalized as strings.
  • If your supplier gives quantities in Arrivage Disty, add it and the tool will adapt.
  • Everything stays offline in your browser. No files are uploaded anywhere.
